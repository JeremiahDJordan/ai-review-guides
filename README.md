# AI review guides

Guides for reviewing large changes with AI reviewers and human reviewers. Each guide says what the change is, where
to start, what each part changes and what to check in it. Triage reports list open work and what to do with it.

Read them as web pages: <https://jeremiahdjordan.github.io/ai-review-guides/>

| Guide | Change |
|---|---|
| [Apache SAI fixes restored on DataStax main-5.0](sai-apache-ports/README.md) | 107 commits that bring Apache Cassandra's Storage-Attached Index fixes into DataStax's Cassandra 5.0 line, with a [one-page overview](https://jeremiahdjordan.github.io/ai-review-guides/sai-apache-ports/overview.html) of what was missing and the [audit report](https://jeremiahdjordan.github.io/ai-review-guides/sai-apache-ports/audit-report.html) behind them |
| [Fork issue triage, 25 November 2026](fork-issue-triage/README.md) | The open bug reports on the [JeremiahDJordan/cassandra](https://github.com/JeremiahDJordan/cassandra/issues) fork grouped by area, with duplicates, merge proposals and the issues already fixed upstream |
